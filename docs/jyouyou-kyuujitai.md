# 常用漢字表（平成22年内閣告示第2号）

`tools/build-mjmap.py` がこのファイルの「対照表」ブロックを読んで、
`mjmap.json` の、旧字体の正字（JIS例示字形の MJ）から新字体の面区点へのエッジ1本にだけ
「常用漢字表の新旧字体」ビット（bit2 = 4）を立てる（364本）。旧字体に包摂・縮退する他の MJ が
新字体へも届くかは `app.js` の `buildEdges` が、選んだ根拠で旧字体に届いたときだけ1段たどって決める。
根拠のビットの並びは `mjmap.json` の `meta.bits` に書いてある。

関連: [jis-suijun.md](jis-suijun.md)（JIS水準との関係）、
[jinmeiyou-kanji.md](jinmeiyou-kanji.md)（人名用漢字）。

## 何のためのメモか

MJ縮退マップには新旧字体の対応が**独立した表としては入っていない**。
會→会 のような対応は「法務省戸籍法関連通達・通知（戸籍統一文字情報 親字・正字）」に
紛れて入っているだけで、法令・告示の段には人名異体字・俗字・誤字が併せて24,695本ある。
そのため「戸籍法通達をONにする」ことは「新旧字体対照を得る」ことと同義ではない。
新旧字体だけを取り出したいなら、常用漢字表そのものを別に持つ必要がある。

逆向きの包含も成り立たない。新旧字体の組のうち7組は戸籍法通達に無く、
包摂規準や告示582号だけで繋がっている（寬→寛、藏→蔵、鄉→郷、夀→寿×3、鎭→鎮）。
新旧字体は戸籍法通達の部分集合ではないので、独立したビットが要る。

古い新聞の翻刻のように旧字体を保存したい用途では、この段を**適用してはいけない**。
逆に検索インデックスを作るなら、この段だけを別キーとして適用するのが有効。

## 常用漢字表は「旧字」とは書いていない

本表の字種欄は通用字体を示し、**当該字種に「いわゆる康熙字典体」に当たる字体がある場合にだけ、
丸括弧に入れて参考として添えている**。文化庁の説明では、これは常用漢字の字体ではなく、
明治以来行われてきた活字とのつながりを示すために添えたもの、とされている。
つまり「対応する旧字」を定めた対照表ではなく、参考情報として括弧書きされているだけである。
「旧字」「旧字体」という語も本表では使われていない。本メモはこの括弧内の字体だけを採る。

### 康熙字典体が示されていない字がある

通用字体と康熙字典体の差が字体の差ではなく字形（デザイン）の差とみなされた字には、
括弧が付いていない。次の32字がそれにあたる。

飲 羽 鋭 益 悦 閲 館 顔 教 戸 呉 娯 告 歳 冊 産 飼 舎 尚 青 清 晴 精 税 説 絶 脱 内 飯 姫 舗 没

青／靑、内／內、戸／戶、教／敎 のように Unicode では別の符号位置を持つ組でも、
常用漢字表は康熙字典体を示していない。**古い新聞にはこれらの字体が実際に現れる**ので、
取り込みたい場合は対照表ブロックに追記すればビットが立つ。本メモは表に載っている分だけを採る。

### 符号化の流儀

康熙字典体が **CJK互換漢字 (U+F900–U+FAFF)** になる字が62件ある。
社の康熙字典体（示偏）は U+FA4C、逸は U+FA67、廊は U+F928。
JIS X 0213 は互換漢字にも独立した面区点を振っている
（社 U+FA4C = 1-89-19、逸 U+FA67 = 1-92-57、廊 U+F928 = 1-84-14）ので、
面区点レベルでも旧新は別の位置になる。全364組で旧新の面区点が異なることを確認済み。

## 出典と取得経路

一次資料は文化庁「常用漢字表（平成22年11月30日 内閣告示第2号）」の本表だが、
[公開PDF](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/kanji/)
は文字が埋め込まれていない画像で、機械可読ではない。

そこで [ikawaha/kanji](https://github.com/ikawaha/kanji) から取った。同パッケージは
常用漢字を「標準字体2,136字・旧字体364字・許容字体5字」として `unicode.RangeTable`
で持ち、平成22年内閣告示第2号を典拠として明示している。

- 旧字体364字・許容字体5字 … `regularuse_table.go` の `OldFormRangeTable` / `TolerableRangeTable`
- 通用字体との対応 … `testdata/golden_jyouyou_H22-11-30.csv`
  （本表2,136字を1行1字で収め、字種欄が `亜（亞）` `弁（辨）（瓣）（辯）` `餅［餅］（餠）`
  の形で括弧を保持している）

CSVの括弧から取った361組に、弁の3組（辨・瓣・辯）を加えて364組。
`OldFormRangeTable` の364字と過不足なく一致することを確認済み。
