# JIS水準と常用漢字・人名用漢字の関係

`index.html` の一覧は JIS X 0213 の水準で区切っている。よく「第1水準＝常用漢字」と
思われるが別物なので、件数を控えておく。面区点は `mjmap.json` の `jis` 表から引いた。

水準の境界は 第1水準 = 1-16-01〜1-47-51、第2水準 = 1-48-01〜1-84-06、
第3水準 = 1-14-01〜1-15-94・1-47-52〜1-47-94・1-84-07〜1-94-94、第4水準 = 面2。

## 第1水準と常用漢字は別物

| | 字数 |
|---|---|
| JIS第1水準漢字 | 2,965 |
| うち常用漢字 | 2,102 |
| うち常用外 | 863 |
| 常用漢字 | 2,136 |
| うち第1水準の外 | 34 |

第1水準は1978年にJISが使用頻度で選んで音訓順に並べたもの、常用漢字は1981年
（現行は2010年）に国語審議会・文化審議会が定めたもので、策定主体も時期も目的も違う。
「ほぼ重なるが、どちらも相手を包含しない」関係になる。

### 第1水準の外にある常用漢字 34 字

すべて2010年改定で追加された196字の一部。

第2水準 30字: 丼 傲 刹 哺 喩 嗅 嘲 彙 恣 惧 慄 憬 拉 摯 曖 楷 毀 璧 瘍 箋 籠 緻 羞 訃 諧 貪 踪 辣 錮 鬱

第3水準 4字: 剝(1-15-94) 塡(1-15-56) 頰(1-93-90) 𠮟(1-47-52)

第3水準の4字は JIS X 0208 に無く、JIS X 0213 で追加された字である。

## 人名用漢字の水準内訳

人名用漢字は常用漢字以外で子の名に使える漢字（864字）。常用漢字との重複は0字。
子の名に使える漢字は 常用漢字 2,136 ＋ 人名用漢字 864 ＝ 3,000 字。
詳細は [jinmeiyou-kanji.md](jinmeiyou-kanji.md)。
