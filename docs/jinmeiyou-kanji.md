# 人名用漢字（子の名に使える漢字）

常用漢字以外で子の名に使える漢字。戸籍法施行規則別表第二に定められ、法務省が
[子の名に使える漢字](https://www.moj.go.jp/MINJI/minji86.html) として公開している。
`index.html` では使っていないが、MJ縮退マップを人名の文脈で読むときの前提として控えておく。

## 件数

| | 字数 |
|---|---|
| 常用漢字（標準字体） | 2,136 |
| 人名用漢字 | 864 |
| 子の名に使える漢字 合計 | 3,000 |
| 常用漢字との重複 | 0 |

JIS X 0213 の水準内訳は次のとおり。全字が JIS X 0213 に含まれる。

| 水準 | 字数 |
|---|---|
| 第1水準 | 566 |
| 第2水準 | 193 |
| 第3水準 | 105 |

第2・第3水準に約3分の1が入るため、人名を第1・第2水準に落とし込もうとすると
必ず縮退が要る。どの根拠まで使ってよいかは [jyouyou-kyuujitai.md](jyouyou-kyuujitai.md)
の議論と同じで、法務省戸籍法関連通達（戸籍統一文字情報 親字・正字）はまさに
この文脈のために作られた段である。

## 出典と取得経路

[ikawaha/kanji](https://github.com/ikawaha/kanji) の `for_personal_name_table.go`
（`DesignatedForPersonalNamesRangeTable`）から抽出した。同パッケージは法務省の
上記ページを典拠としており、更新履歴を持つ。

| 日付 | 内容 |
|---|---|
| 2026年6月26日 | 「勒」(U+52D2) を追加（計864字） |
| 2017年9月25日 | 「渾」を追加（計863字） |

人名用漢字は法務省令の改正で随時増える。ここに写した時点は上記の864字である。
