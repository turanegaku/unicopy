# コピーできる字の対応範囲

`index.html` の一覧は JIS X 0213・MJ文字情報一覧表・人名用漢字・`tokenizer.json` という
出所の違う4つの字集合を1枚の画面に重ねている。どれも「漢字の集合」だが範囲は揃っておらず、
重なり方も一様ではない。どこがどう食い違うかをここに控えておく。
数字は 2026年9月14日時点の `index.html` / `mjmap.json` / `tokenizer.json` から数えた。

関連: [jis-suijun.md](jis-suijun.md)、[jinmeiyou-kanji.md](jinmeiyou-kanji.md)、
[jyouyou-kyuujitai.md](jyouyou-kyuujitai.md)。

## 区分ごとの枚数

| 区分 | 枚数 | 出所 |
|---|---|---|
| 記号 | 5 | 々〻〆〇ヶ（漢字ではないので水準に出ない） |
| 第1水準 | 2,965 | JIS X 0213 1面 |
| 第2水準 | 3,390 | JIS X 0213 1面 |
| 第3水準 | 1,259 | JIS X 0213 1面 |
| 第4水準 | 2,436 | JIS X 0213 2面 |
| MJ外字 | 44,349 | MJ文字情報一覧表のうち水準字へ縮退しないもの |

水準字は 10,050 字。MJ外字は枚数で、基底の字種では 42,363 字（同じ基底にIVSの違う
別字形が複数枚あるため）。縮退の根拠のチェックを切ると縮退先を失うMJが外字へ回るので、
この枚数は設定で動く。

## 人名用漢字 ⊂ JIS X 0213

戸籍法施行規則別表第二の864字は全部 JIS X 0213 の中にある。外にはみ出す字は1つも無い。

| | 第1水準 | 第2水準 | 第3水準 | 第4水準 |
|---|---|---|---|---|
| 人名用漢字 | 566 | 193 | 105 | 0 |

外字の部分集合ではないので一覧では水準の区分にそのまま入れ、部首や検索と同じ
絞り込み（「人名用漢字だけ」）として切り出せるようにしてある。
第2・第3水準に298字（約3分の1）あるので、名前を第1水準だけに落とそうとすれば
必ず縮退が要る。第4水準には1字も無い。

## tokenizer.json は何を採っているのか

`tokenizer.json`（WordPiece・語彙7,098）の1文字トークンは7,085。うちこの一覧の
カードに現れるのは6,547字で、カード右上の丸で示している。
残る538字はASCII・かな・囲み数字など、漢字の一覧には出ない字。

| 区分 | 語彙にある | 全体 |
|---|---|---|
| 記号 | 5 | 5 |
| 第1水準 | 2,965 | 2,965 |
| 第2水準 | 3,390 | 3,390 |
| 第3水準 | 132 | 1,259 |
| 第4水準 | 12 | 2,436 |
| MJ外字（基底の字種） | 38 | 42,363 |

### 土台は JIS X 0208

第1・第2水準は1字残らず入っている。この 2,965 + 3,390 = 6,355 字は
JIS X 0208 の漢字全体とちょうど一致する。語彙の骨格が
「Shift_JIS で書ける漢字は全部入れる」で作られていることは、まず間違いない。

### その外側には基準が無い

第3水準 1,259 字のうち採られているのは 132 字（10%）。内訳は次のとおり。

| 内訳 | 字数 | 例 |
|---|---|---|
| CJK互換漢字（NFC正規化で第1/2水準に戻る） | 56 | 塚 U+FA10 ／ 神 U+FA19 ／ 逸 U+FA67 |
| 常用漢字表の康熙字典体（統合漢字側） | 34 | 亞 圓 敏 |
| どちらにも当たらない | 42 | 俱俠偁凞厲咜咩嘈嚙嚩囉囊埵塡壔剝屢挹搔摑毗淼潑煑禱簞繡菪萊蔣蟬蠟袪醬銈顚驒鹼麴屛幷繫 |

「常用漢字の異体字を拾おうとした」という筋は一応見える。しかし第3水準にある
康熙字典体102字のうち17字は逆に落ちている。

> 侮 倂 喝 廊 憎 暑 欄 殺 渴 煮 甁 碑 禍 虜 鬭 麵 瘦

同じ字体の常用漢字側（U+6B04 欄 など）はどれも語彙にあるので、
これらの名前や固有名詞をそのまま流すと `[UNK]` になる。

第4水準に至っては 2,436 字中 12 字だけで、規格でも字体表でも説明がつかない。

> 劄 𢌞 抦 揷 滊 澥 猽 痹 睪 缼 譃 迠

MJ外字から拾われている 38 字にも、切 投 男 直 朝 査 恵 従 舎 替 鶴 のような
常用漢字そのもの（IVS付きMJ字形として外字に回っている字）が混じる。

さらに、JIS X 0213 の外にある漢字も60字入っている。その多くは
[jyouyou-kyuujitai.md](jyouyou-kyuujitai.md) が「常用漢字表が康熙字典体を
示していない32字」として挙げている字の旧字形にあたる。

> 內 吳 吿 姬 娛 尙 强 彥 悅 戱 戶 敎 旣 昻 查 栅 歲 淸 玆 產 畵 稅 絕 脫 銳 閱 靑

### 結論

一貫した根拠は **JIS X 0208 全字** までで、そこから先は規格でも字体表でも
説明がつかない。取りこぼし（第3水準の康熙字典体17字）と余剰（第4水準の12字、
外字の38字、JIS外の60字）が両方あるので、字体表や規格を基準に線を引いたのではなく、
学習コーパスに出現した字をそのまま拾った残差と見るのが妥当である。

名前や古い文書を通すなら、語彙の有無をあてにせず、縮退ツリーの新旧字体の線で
第1・第2水準まで潰してから渡すほうが確実になる。

## 縮退の根拠のビット

`mjmap.json` の `mj` は `[MJ番号, 字形, [[面区点のindex, 根拠のビット], ...]]` で、1本の
エッジに複数の根拠が立つ。並びは同じファイルの `meta.bits` に持たせてあるので、読む側は
それだけ見れば組み立てられる。強い順に並べてあり、線種は立っている根拠のうち
一番強いもので決まる。

| bit | 根拠 | 本数 | 線種 | 一覧のチップ |
|---|---|---|---|---|
| 0 | JIS例示字形 | 10,063 | 実線 | （常に有効） |
| 1 | JIS包摂規準・UCS統合規則 | 14,515 | 実線 | 包摂・統合 |
| 2 | 常用漢字表の新旧字体 | 364 | 橙の実線 | 新旧字体 |
| 3 | 戸籍統一文字情報 親字・正字 | 16,305 | 破線 | 戸籍／親字・正字 |
| 4 | 民一2842号通達別表 誤字俗字・正字一覧表 | 1,001 | 破線 | 戸籍／誤字俗字 |
| 5 | 民二5202号通知別表 正字・俗字等対照表 | 138 | 破線 | 戸籍／正字・俗字 |
| 6 | 法務省告示582号別表第四 | 12,568 | 破線 | 告示582号 |
| 7 | 辞書類等による関連字 | 15,958 | 点線 | （出さない） |
| 8 | 読み・字形による類推 | 413 | 点線 | （出さない） |

bit0 は xlsx 側の情報で、「X0213 包摂区分」が0（＝包摂規準を当てずにその面区点に
対応している字形）かつ「実装したUCS」が入っている、その面区点の正字を指す。
区分0は1つの面区点に複数あることがあり（10,909本／10,054面区点）、
愛(1-16-06) は MJ011751(E0102) と MJ011752(E0101) の両方が区分0だが、
実装したUCSを持つのは MJ011752 だけなので、これで正字が1つに決まる。
根拠の選択の対象ではなく、包摂のチェックを外しても残る。

bit2 だけが縮退マップの外から来る（[jyouyou-kyuujitai.md](jyouyou-kyuujitai.md) の対照表）。
bit3〜5 は縮退マップでは「法務省戸籍法関連通達・通知」ひとまとめだが、
出典の違う3つの寄せ集めなので `種別` で割ってある。ほとんどは親字・正字で、
誤字俗字・正字一覧表は 1,001本、正字・俗字等対照表は 138本しかない。
割っておかないと「正字の関係だけ採る」ができず、誤字までいっしょに付いてくる。

bit7・bit8 は縮退の根拠としては弱すぎて常用しないので、データには持つが
チップは出していない。出すなら `SRC` の `hidden` を外すだけでよい。

縮退先は MJ にぶら下げてあり、面区点も字形も生のUnicode文字で持つ
（`ensure_ascii=False`）。別配列にして添字を2つ持たせていた頃より 2,128KB → 1,611KB
小さく、読む側も16進のデコードが要らない。

## 同じ字が2回出ることについて

ツリーは「1行 = 1 MJ字形」で、行は一覧のカードの下にぶら下がる。
複数のJIS字に縮退するMJは、その縮退先のカードそれぞれの下に現れる。

例えば MJ006815（倂+E0102）は 1-14-28 倂 と 1-42-27 併 の両方を縮退先に持つので、
併 の群と 倂 の群の2か所に出る。どちらの群でも 1-14-28 のノードが描かれるため、
部首などで両方が近くに並ぶと 1-14-28 が2回見える。これは逆引きとして正しい状態で、
以前のコミットの取りこぼしではない。

群まるごとが重複する場合（惡 の群が 悪 の群と同じMJ・同じ縮退先しか持たない場合）
だけは一本化していて、部分的に重なる場合は畳んでいない。

## IVS と字形

カードの字形は CSS のフォント指定で決まる。IPAmj明朝が入っていれば MJ字形どおりに
描けるが、入っていなくても macOS の明朝体が一部の IVS を持っているため、
逸+E0104(MJ025996) と 逸+E0108(MJ030234) のように字形が描き分かることがある。

バッジ（「MJ字形: IPAmj明朝」「MJ字形: 既定の明朝」）が示すのは
**いま何のフォントで描いているか**で、IVS が描けるかどうかとは別。
IPAmj明朝を検出できたかどうかはバッジの tooltip に出る。検出はフォント名の
問い合わせしか見ていないので、入っていても外すことがある。
